# Ireland Cost-of-Living and Inflation Tracker

## 1. Project Overview

This project analyses Consumer Price Index (CPI) inflation in Ireland using official data from the Central Statistics Office (CSO).

Python and Pandas are used to retrieve and clean the data, SQLite is used to store and analyse it using SQL, and Matplotlib is used to visualise historical inflation trends.

## 2. Key Findings

- **Housing and energy:** Experienced substantial inflation increases during 2021–2023, with a year-over-year inflation rate reaching approximately 28% at its peak.
- **Food and non-alcoholic beverages:** Inflation rose significantly during 2022–2023, reaching approximately 13%, before easing.
- **Overall CPI:** Inflation increased during 2021–2022 and subsequently slowed.
- **Inflation versus prices:** A declining inflation rate does not necessarily mean prices are falling. It can mean that prices are increasing more slowly than before.

## 3. Tools and Technologies

- Python
- Pandas
- SQLite
- SQL
- Matplotlib
- Official CSO CPI data

## 4. Data and Scope

The cleaned dataset contains 4,646 observations across 13 commodity groups, covering November 1976 to December 2025.

The recent-period visualisation focuses on January 2020 to December 2025.

## 5. Limitations

This project describes historical inflation trends. It does not establish the causes of inflation, measure the exact spending of individual households, or forecast future inflation.

The analysis uses the observations available in the downloaded dataset, which ends in December 2025.

## 6. Conclusion

This project demonstrates a complete introductory data analytics workflow, from retrieving and cleaning official data to storing it in a database, analysing it with SQL, and communicating findings through visualisations.
